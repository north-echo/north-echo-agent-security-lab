# v2.0.0-beta.1 — beginner-first learner review

Prerelease for learner walkthrough and feedback, not a stable teaching-quality
or production-containment certification. No course-duration or retention claim.

## Curriculum

- B0 terminal/program refresher and independent reader; B1 useful environment
  handoff with independent practical.
- Rewritten introductions, guided lessons, independent preparation, and manual
  chapters for Modules 01-12. Exact file access, complete small source listings,
  local explanations, prediction/failure/repair/checkpoint, limits, and reset.
- New practiced bridges for C environments/descriptors/capabilities, anchored
  writes, failure aggregation, and independent 0/7/0 runtime jobs.
- Capstone transfers single-job skills to validated ordered batches, preserves
  ordinary failures, checks effective per-job limits and exact collection, and
  requires a separately reviewed rationale.
- Modules 11-12 explicitly separate fixed local models, hinted dispatch, and
  supplied evidence rows from real Linux enforcement and independent discovery.

## Runtime and reliability corrections

Registered bounded service lifecycles, literal systemd argv, ownership-before-stop,
specific OOM/PID-limit evidence, setup-failure rejection, signal-aware synthetic
fixture cleanup, framed/bounded broker messages, strict input types, accurate
HMAC/replay limitations, narrower proc grant, mandatory descriptor hygiene,
all-capability observations, complete evidence validation, and non-executing
package integrity checks. Tests replay documented commands and all independent
preparation paths; the capstone rejects premature launch before later validation.

## Deployment and compatibility

Fedora 44 ARM64 is the preferred new-install beta baseline on Apple Silicon:
pinned image, SELinux enforcing, shared Fedora package list, no host mounts or
agent forwarding, checksum-verified tagged course, idempotent marker, and strict
readiness. Fedora x86-64 is not claimed. Ubuntu remains a separate compatibility
template and dual-architecture CI baseline. Both templates accept beta version
pins and verify the exact archive inventory before extraction.

Install into a **new** instance. Do not extract over existing student work.
Restarting v1.0.2 intentionally does not upgrade it. Export private work before
deleting any VM. Package repositories can change; deployment evidence records
the actual installed revisions.

## Evidence and remaining limits

See the exact candidate records under `validation/*-rewrite-20260919/`, the
release acceptance record, and `docs/SOURCE_TRUTH.md`. Automated passes do not
establish novice comprehension; please report the first unexplained step, your
prediction, actual output, and the hint needed. Keep solutions and real terminal
history private.

This remains a disposable-VM course, not a production sandbox, hostile multi-user
grader, all-channel confidentiality system, or autonomous offensive workflow.
Landlock ABI 7 does not enforce ABI 9 pathname Unix-socket connection rights.
Same-account teaching roles are not isolated by mode-0600 files. Broker replay
state is process-local. Evidence packages are unsigned byte inventories.
