# Module 04 - Build a minimal tool-using agent (scaffold)

Planned outcome: build a small deterministic agent loop with `read_file`, `write_file`, and argv-based command execution over synthetic tasks. Begin deliberately over-authorized, inventory inherited authority, then define a tool contract. No production API credential will be required; a local scripted policy/model fixture will be the default.

Planned guided lessons: tool loop and trace; structured arguments and failure handling; authority inventory. Independent lab: implement a reproducible local tool runner with complete action records.
